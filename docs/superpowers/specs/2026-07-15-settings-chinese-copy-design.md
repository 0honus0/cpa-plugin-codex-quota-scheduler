# 调度设置中文文案设计

## 目标

把设置区直接展示给中国用户的英文技术词替换为易懂中文，并解释两个与额度探测相关的开关。底层配置键、Management JSON、导入导出格式和运行行为保持不变。

## 文案调整

| 当前位置 | 新中文文案 |
| --- | --- |
| `启用自动 reset probe` | `自动激活新的额度周期` |
| reset probe 说明 | `当额度重置时间已经到达，但 OpenAI 尚未生成新的额度周期时，发送一次极小的 Codex 请求尝试激活新周期，然后重新读取额度确认结果。可能消耗少量额度。` |
| `启用 provisional roster Probe 风险模式` | `账号列表未确认时仍允许额度探测（高风险）` |
| provisional roster 说明 | `CPA 暂时无法确认当前账号及优先级时，允许插件使用最近一次保存的账号列表执行额度重置探测。每次都会重新验证账号凭据，但仍无法保证账号未被删除或调整优先级。通常应保持关闭。` |
| `Monthly 模式` | `月度账号使用方式` |
| `优先使用 Monthly` | `优先使用月度账号` |

`按到期时间排序` 保持不变。

## 行为边界

- `enable_reset_probe`、`probe_on_provisional_roster`、`monthly_mode` 等配置键不改名。
- 不修改默认值、保存逻辑、导入导出结构或调度行为。
- 自动额度周期探测仍同时管理存在的 5 小时窗口和 Weekly/Monthly 长窗口；缺失 5 小时窗口时只处理长窗口。
- “账号列表未确认时仍允许额度探测”只是风险授权：仅允许经过凭据验证的额度重置探测，不启用普通后台刷新，也不把旧账号列表升级为权威 roster。
- 英文界面保留现有英文术语，仅调整中文界面。

## 页面呈现

两个开关各自带一行较弱视觉层级的帮助文字，放在开关标题下方。风险开关说明明确标注“通常应保持关闭”，避免用户把它当成性能增强选项。

## 测试

- 资源页面必须包含上述纯中文标签和说明。
- 中文设置区不得再出现 `reset probe`、`provisional roster` 或 `Monthly 模式`。
- 配置字段名和设置 round-trip 测试保持通过，证明只改展示文案。
